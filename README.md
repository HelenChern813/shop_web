# Проект 3 - Сайт магазина
Разрабатывается приложение и сайт для онлайн магазина. Функции и возможности будут уточнться по мере разработки


## Разработка
В модуле src лежат файлы для бекенд обработки проекта
В модуле catalog лежат файлы содержащие код страницы
В оставшихся модулях лежат сопроводительные файлы для работы проекта


### Установка зависимостей
Для установки зависимостей, выполните команду:
```sh
poetry update
```
или
```sh
poetry install
```




### Зачем вы разработали этот проект?
Для отработки навыков программирования, повышения квалицикации
